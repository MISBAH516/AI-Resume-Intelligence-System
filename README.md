# 📄 AI Resume Intelligence System

An AI-powered Resume Analysis platform built using Python, Streamlit, and Ollama.

This project helps users analyze resumes, match resumes with job descriptions, and generate AI-based interview questions using Local Large Language Models (LLMs).

---

# 🚀 Features

## ✅ Resume Analyzer
- Upload PDF resumes
- Extract resume text automatically
- AI-powered resume evaluation
- Resume scoring system
- Skill analysis
- Missing skills detection
- Career recommendations

---

## ✅ Job Matcher
- Compare resume with job descriptions
- ATS-style matching system
- Match percentage generation
- Missing keyword detection
- Improvement suggestions

---

## ✅ Interview Question Generator
- HR interview questions
- Technical interview questions
- Python questions
- Machine Learning questions
- Project-based interview preparation

---

# 🧠 Technologies Used
